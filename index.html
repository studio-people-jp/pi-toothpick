THE MATHEMATICS

How can a toothpick reveal π?

When a toothpick of length L is randomly dropped onto parallel lines spaced d apart (with L ≤ d), the probability of crossing a line is:

P(crossing) = 2L⁄πd

So, with N drops and K crossings, we can estimate:

π ≈ 2LN⁄dK

This project uses L = 1 and d = 2. The estimate is statistical, so it becomes more reliable as the number of drops grows.
